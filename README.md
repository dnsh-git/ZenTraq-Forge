# ZenTraq Forge

A lightweight, responsive gym tracking web application designed to help users log workouts, monitor fitness progress, and manage their training history through a clean, intuitive interface.

## Overview

Zentraq Forge aims to make workout tracking simple and organized. The goal is to build a practical fitness tool that helps users maintain consistency, record training sessions, and review their progress over time.

## Planned Features

- **Workout Logging** — Record exercises, sets, reps, and weights.
- **Workout History** — Review previous training sessions.
- **Progress Tracking** — Monitor changes in training performance over time.
- **Dashboard** — View workout summaries and key fitness statistics.
- **Responsive Interface** — Use the application across desktop and mobile screens.
- **Local Data Persistence** — Keep workout records available between sessions.
